# 쇼핑몰 상담 웹 클라이언트

ApiController의 POST /chats와 대화 내역 삭제 API를 분석하여
HTML, CSS, Vanilla JavaScript로 채팅 화면을 작성해 줘.
파일은 src/main/resources/static에 생성해 줘.

- 상단 헤더에는 사용자 이름 입력란과 새 대화 버튼,
  가운데에는 대화 영역, 하단에는 메시지 입력란과 전송 버튼을 배치한다.
- 사용자 메시지는 오른쪽, AI 답변은 왼쪽 말풍선에 표시한다.
- 사용자 이름을 입력한 뒤 대화할 수 있도록 한다.
- 페이지를 열 때 대화 아이디를 UUID로 생성하고, 같은 대화에서 유지한다.
- 스트리밍 답변은 하나의 말풍선에 누적하고 공백과 줄바꿈을 유지한다.
- 응답 중에는 전송 버튼이 중지 버튼으로 바뀌며,
  중지해도 이미 표시된 답변은 유지한다.
- 새 대화 버튼을 누르면 수신을 중지하고 현재 대화 내역을 API로 삭제한다.
  삭제 성공 후 새 UUID를 생성하고 대화창을 비우며 사용자 이름은 유지한다.
- Enter는 전송, Shift+Enter는 줄바꿈으로 동작한다.
- 오류를 안내하고 다시 사용할 수 있도록 하며,
  모바일과 데스크톱에서 사용할 수 있게 구성한다.
