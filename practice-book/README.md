## 실습 환경과 진행 방법

각 프로젝트를 새로 만들 때는 해당 장의 Spring Initializr 캡처를 보고 의존성을 선택합니다. 공통 설정은 Gradle - Groovy, Java, Group `com.example`, Artifact `demo`, Package name `com.example.demo`, Jar, Properties, Java 21입니다. Spring Boot 버전은 배포된 예제 프로젝트의 `build.gradle`을 기준으로 맞춥니다.

Generate로 내려받은 ZIP 파일을 압축 해제하고, 폴더 이름을 각 실습의 프로젝트 이름으로 정한 뒤 IntelliJ IDEA에서 엽니다. Gradle 의존성 다운로드가 끝나면 실습 코드를 작성합니다. 캡처 이미지는 이 문서를 기준으로 `images/장별 폴더/`에 저장되어 있습니다.

- Java 21과 IntelliJ IDEA를 사용합니다. 각 모듈은 독립 Gradle 프로젝트입니다.
- 실행 코드와 의존성의 기준은 각 프로젝트의 실제 파일입니다. 코드 블록 위의 파일 링크로 원문을 열 수 있습니다.
- 메서드 발췌는 링크에 표시한 기존 클래스 안의 코드입니다. 발췌만 새 파일에 붙이지 말고 프로젝트의 package·import·클래스 선언·주입 필드와 함께 읽습니다.
- 앱은 각 프로젝트의 DemoApplication으로 실행합니다. 웹 모듈은 기본 8080 포트를 공유하므로 하나씩 실행합니다.
- JDBC·MyBatis·JPA·REST는 MariaDB와 DB_URL·DB_USER·DB_PASS 환경변수를 사용합니다. 앱과 테스트 실행 설정에 모두 적용합니다.
- MVC·Security는 H2 메모리 DB를 사용하며 앱 종료 시 데이터가 사라집니다. spring-thymeleaf는 DB 없이 실행합니다.
- MyBatis·JPA는 @Test를 하나씩 실행하고 로그를 관찰합니다. REST 장에서 assertThat·MockMvc·Mockito로 자동 검증을 배웁니다.

## 데이터와 예상 결과의 기준

회원 샘플은 윤서준(10)·윤광철(43)·공미영(23)·김도윤(10)입니다. 이메일은 각 실습의 @campus.com 주소를 사용합니다. 신규 회원 실습은 정혁 / JungHyuk@campus.com / 10살입니다.

공통 SQL은 회원 4명과 게시글 100개를 준비합니다. MariaDB를 이어 쓸 때 data.sql을 중복 실행하지 않습니다. HTTP로 등록한 정혁이 남아 있으면 다음 등록·일괄 가입 실습 전 삭제합니다. MyBatis·JPA 테스트는 종료 후 변경이 롤백되지만 자동 증가 ID가 초기화되는 것은 아닙니다.

본문의 **예상 결과**는 제공된 샘플과 각 실습의 시작 조건을 기준으로 설명한 결과입니다. 모든 환경에서 재실행해 수집한 로그 전문이 아닙니다. 실제 ID·실행 시각·SQL 출력 형식은 달라질 수 있고, 데이터가 추가되면 개수·페이지 수도 달라집니다. 명시적으로 정렬하지 않은 결과 순서는 가정하지 않습니다.

Security는 로그인 회원 4명과 상품 2개의 전용 SQL을 사용합니다. 계정 비밀번호는 5장의 실습 계정 표를 참고합니다. 화면은 기본 HTML로 구성하며 자체 CSS는 사용하지 않습니다. MVC는 학습한 공통·페이징 fragment를 사용하고, Security는 화면마다 필요한 링크와 폼을 직접 작성합니다.

## 코드 읽기와 실행 결과 확인

실습마다 다음 세 가지를 먼저 확인합니다.

1. 어느 입력을 어떤 Controller·Repository·Mapper 메서드에 전달하는가?
2. 반환값은 엔티티·DTO·목록·Page·화면 이름 중 무엇인가?
3. 로그·HTTP 상태·화면·DB 중 어디에서 결과를 확인하는가?

실습 도중 문법을 모두 외우기보다 값을 한 개 바꾼 뒤 예상 결과와 비교해 봅니다. 테스트를 실행할 때는 다른 테스트의 실행 순서에 의존하지 않습니다. 외부 DB 실습에서는 연결 오류와 검증 실패를 구분합니다.

## Word 변환을 위한 문서 규칙

1장은 01 파일, 2장은 02 도입과 02-1·02-2·02-3 파일, 나머지는 03·04·05 파일 순서로 합칩니다. 이 README는 전체 안내입니다.

장 제목은 #, 주요 절은 ##, 실습 소절은 ###를 사용합니다. 2.1·2.2·2.3 파일은 2장의 하위 절이므로 ##로 시작합니다. 번호는 제목 텍스트에 포함되어 있습니다. Word에서 자동 번호를 추가할 경우 중복되지 않도록 한 방식만 사용합니다.

코드 블록은 java·sql·xml·properties·html·http·groovy 언어를 구분합니다. 코드와 설명을 함께 읽을 수 있도록 소절 단위로 구성했으며, 외부 링크를 클릭하지 않아도 주요 실습 코드와 예상 결과를 본문에서 볼 수 있습니다.
